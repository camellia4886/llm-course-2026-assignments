# L3-P226 思考题

后训练反馈与计算成本　·　L3 Part 2 第 224、226 页及第 226 页备注

单 token 教学实验中，两臂各训练 160 轮，留出成绩同为 13/21。组相对路线用了 320 次更新和 40,960 次奖励判定。

## 扩展报告核验

综述扩为六页，新增等训练轮、等参数更新与验证预算的比较。两臂同为 160 次参数更新时，SFT 为 13/21，组相对路线为 10/21，后者已做 20,480 次奖励判定。等轮数终点同为 13/21，对应的更新与验证成本却不同。

## 核验结果

在 arms 的两组 history 中找相同更新次数。SFT 每轮更新 1 次，组相对更新每轮 2 次。第 160 次更新时，两者得分分别来自第 160 轮和第 80 轮，正确数分别为 13/21 和 10/21。
