# L2-P13 思考题

中文改错的误改与漏改　·　L2 Part 1 第 13、48、147、230、256、276 页

在 12 条自拟句上，两种去重规则都修好 4/6 个错句。将规则限于“了”和“的”后，合法句误改从 4/6 降为 0/6。

[下载 Word 报告](L2-P13%20思考题.docx)　·　[课程作业索引](../../README.md)

## 核验结果

看“请看看这份材料”与“他到了了”两行。宽规则会把两句都去重，窄规则只改后一句。按预期列逐句检查，6 个无错句中，宽规则误改 4 句，窄规则误改 0 句。
