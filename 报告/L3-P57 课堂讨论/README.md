## 扩展报告核验

扩展稿将两段真实模板的 17 个监督位置单独列账。样本等权时每段贡献一半，有效 token 等权时第二段占 15/17。报告还写清了因果移位、填充和助手轮次掩码该怎样逐位置核验。

## 核验结果

先看 example_target_counts，短、长样本各贡献 1、3 个有效位置。分别按样本和 token 平均得到 1.241368 和 1.837758；图 1 的 50% 和 75% 对应这两种长样本权重。
