# 课堂习题与案例作答

页码使用幻灯片文件的实际页序。已有思考题的补充见本页与 [原思考题合集](../思考题合集.md)。

## L1 第 22、24 页与第 164–191 页

**单位与失效。** 字符是抽象文字单位，字形是其可见呈现，词是语义和句法单位，token 由计算接口决定。可用 OCR 的异体字和 BERT 对 “WTO” 的跨度做例子。把两个异体字归一成同一字符是编码区别丢失，识别出正确字符却把“王某”接错人物则是语境消歧问题。RAG 切分发生在传统分段和指代仍有价值的场景。固定同一资料，用保留标题与代词先行词的片段对比硬截断，检查证据命中和答案蕴含是否共同改善。

| 案例 | 明确目标 | 一个最小对照 |
|---|---|---|
| 小红书风格指数 | 将风格、情感、立场和意图各自标注，质量以事实与用途单查 | 固定事实，改平台口吻，风格分应变，事实判定应稳定。按事件和时间留出。 |
| 商业敏感信息 | 分别标内容命中、适用授权和最终处置 | 同段价格信息换成不同接收者，检测结果保持，处置按可信授权改变。 |
| 古籍 OCR | 区分逐字转写、候选推定和补字，保留页行及校勘依据 | 固定疑似字形，给不同版本证据，核对原始转写和候选变化。CER 之外看异体、行序及可回查性。 |
| 古汉语信息抽取 | 实体边界、身份、任职关系、时态及证据分别保存 | 固定人名官名，改“拟任”为“任”，关系状态改变；冲突版本保留各自来源。 |
| 翻译和术语 | 文档级术语、指代和关系保持与可读性分开检查 | 固定原文，比较显式术语记忆与更长上下文，核对同一术语及例外是否一起保留。 |
| RAG 切分 | 检索命中文档与回答有据是两项指标 | 固定检索器和 token 预算，比较固定长度和带标题/先行词的片段；记录召回、噪声和答案引用。 |

内省可以生成假设，观察语料能揭示分布，受控实验用于区分解释。出现冲突时先查定义、样本覆盖和权重。Benchmark 定义一套操作和指标，平均准确率可能掩盖少见错误或代价差异。最小对照中应固定其他条件，再改变决定答案的一处，另留答案应稳定的控制对。读报告时补齐样本、基线、工具权限和推理预算；一次成功只能支持该输入与配置下的可行性。

### L1 第 295 页 LAS

1. **字符改子词。** 子词序列更短、可捕捉词内结构，但低资源与罕见专名易受词表限制，音频对齐边界变粗。用同音频、同数据量对比 CER、WER、专名准确率及解码耗时。不同切分方案先还原到统一文本单位。
2. **流式。** 传统全局注意力可能等待完整音频。可比较因果或分块编码器、单调注意力和 MoChA（单调定位后在小窗口做软注意力），控制可看未来帧。测首 token 延迟、最终延迟、实时率和 CER，单独检查长停顿、修正及块边界。
3. **Transformer 替换。** 并行训练能利用更长依赖，长音频显存和流式缓存需要额外设计。保持训练数据、词表、解码束宽和训练预算一致，比较 RNN LAS、离线 Transformer，以及采用因果／局部掩码的流式版本。

## L2 Part 1 第 13、48、147、230、256、276 页

- **语法改错。** 输入句子及语言变体，输出最小编辑和可选解释。相同信号可来自人工成对改写、带错误类型的受控扰动或授权语料。用编辑级 P/R/F0.5、语义保真和无错句误改率验收。基础任务继续作为系统接口和指标，是否单设模块看成本和失败模式。信息检索与 NLP 在语义匹配、切分和查询理解交集很大，也包括排序、索引等独立问题。
- **分段。** 中文面临主题边界、无空格及引号段，英文还受缩写和大小写影响。RAG 需要让段落含有证据和指代先行词。按文档、来源和主题隔离训练、验证；正例为自然段落转折，负例为同段候选切点，保留无明显边界样本。中文已另跑新闻话题边界代理实验；跨语言比较另用独立真实段落金标。
- **影视推荐。** 用户观看序列可训练共现 embedding 或序列模型，演员仅是内容特征。类型可由多标签、语义聚类和用户序列共同表达。新影片缺少行为时先用简介、导演、演员等内容表示，随交互增长再更新。按上线时间验证冷启动 Recall@K、多样性与已核验的相关性。
- **Pre-LN 与 RMSNorm。** 预归一化能改善深层梯度传播，后归一化在部分浅层或特定调参下仍值得比较。RMSNorm 分母基于均方根，保留分量的整体偏移；其雅可比主缩放为 1/rms，并有沿输入方向的修正。固定初始化、学习率、warmup 和深度，分别看梯度、稳定性和测试指标。
- **DeepNet。** 先区分理论可训练与推理串行成本。宽度使多数矩阵参数近似二次增长，层数近似一次增长。DeepNorm 的缩放用残差更新界与初始化共同控制。编码器、解码器和联合结构的常数不同，不能把一个简化式应用到所有模型。MoE 的专家容量和活跃计算各自记录，路由负载与残差稳定性分别核对。
- **注意力头。** 低阶模式可以作为归纳先验，但硬编码会改变域外灵活性。删头、共享 K/V 与固定模式是不同干预。GQA 的结果能支持某些设置下共享 K/V 的工程收益，实际哪些 Q/K/V 更关键需做等预算消融与回归检查。

## L2 Part 2 资源与模型算例

- **第 115 页。** 先统一输入长度、批大小、精度、编译与缓存热态。测预填充、解码和端到端 P50/P95，再用 CUDA 事件与 profiler 分离访存、核启动、通信、padding 和等待。FLOPs 下降而字节搬运量不变时，可观测到计算不是瓶颈。
- **第 123 页。** 训练配方覆盖优化器、学习率曲线、批量、warmup、精度、正则、数据混合与检查点选择。原始 Transformer 给了 Adam 参数、按模型宽度和步数变化的学习率及 warmup、标签平滑和 dropout。固定训练曝光和实际 FLOPs，逐项改配方，多种 seed，使用独立验证；把调参搜索计入费用。
- **第 157 页。** A、B、C 的 6ND 均为 6×10²¹ FLOPs。在 BF16 和十进制 16 GB 权重上限下，A 约 20 GB 超限；B、C 权重约 10 GB。B、C 要曝光 200B，唯一数据上限是 100B，因此需报告重复曝光或新增来源。B 的验证损失更低时，仍要查目标领域错误、回归和实际峰值显存。若 C 目标任务显著更好且回归可接受，选择 C，否则以 B 为基线。
- **第 173 页。** DeepSeek-V3 报告约 671B 总参数、每 token 约 37B 激活、14.8T 预训练 token。报告训练总计约 2.788M H800 GPU 小时。MoE、MLA、FP8 与并行同时出现；单卡存储还取决于完整权重、精度、专家分片或卸载、每个并发请求的缓存和临时开销。不能以 37B 活跃参数乘权重字节直接估显存。 [DeepSeek-V3 原报告](https://arxiv.org/html/2412.19437v2)
- **第 223–224 页。** 7B BF16 权重 14 GB，4×32,768 的 KV 为 16 GiB，总计 31.180 GB。一次解码步主要计算 2NB+4LBsd≈124.72 GFLOPs，设备理想下界约 1.247 ms；若读取约 31.180 GB，带宽下界约 31.180 ms。长度翻倍约 48.360 GB，容量先超限。减并发可缓解容量，代价是同时服务的请求变少。硬件下界未计调度和峰值临时区。

## L3 Part 1 第 19、43、52、54、87 页

把忠实定义为保留否定、时间和例外，简洁定义为最多两句，正式定义为不用俚语并使用统一术语。发生冲突时先保留事实约束，再压句或返回冲突。例题类型分为：

| 类型 | 材料与问题 | 金标 |
|---|---|---|
| 可答 | 资料写“周三前登记”，问周二是否符合 | 是 |
| 缺材料 | 仅写“登记需授权”，问甲已获授权吗 | 信息不足 |
| 冲突 | 同一有效期两份无优先级资料给出不同截止日，问唯一日期 | 资料冲突，需核对版本 |
| 最小对照 | 把“无需交证明”改为“禁止交证明”，问是否明确禁止 | 前者否，后者是 |

开发集覆盖常见条件，测试集换人物、措辞和条件组合，固定题面再选提示；记录相反判断、无故拒答和证据遗漏。第 87 页候选的单评者排序是忠实 B>A>C，自由改写 C>B>A。B 明示外表和内心的反差，A 接近原句但英语可能被理解为无情，C 把下一行的无笑提前融入。公开课件已给候选说明，这里是按两套标准独立打分的课堂演练。

## L3 Part 2 第 236–237 页

**236，解释给定训练结果。** 奖励和 pass@1 提高说明当前设置下首次抽样更容易成功。固定总 token 的成功率基本不变，单次更长吞掉了候选数；大 k 覆盖下降提示多样性降低。机制一是正确候选的概率集中同时低概率可解路径流失。机制二是奖励偏爱长过程或格式，判分器对长轨迹更有分歧。还可能存在任务族混合导致的平均偏差。

按优先级做三项实验。① 固定总 token、硬件和解码，比较短输出多采样与长输出少采样，绘成功率-预算曲线。② 同题使用独立验证器和双人复核抽样，按长度分桶做过程判断，测分歧。③ 追踪检查点、题族和解法簇，比较 pass@k、过程有效覆盖与拒绝采样教师蒸馏。若第一项收益消失且第二项偏差明显，先改奖励与数据；若覆盖确实恶化，优先多样性或蒸馏，再决定扩大 RL。

**237，有限预算路线。** 先定义面向使用者的有据、完整与风格要求，按来源留出独立测试。用少量专家时间标注证据和关键错误，跑提示基线。精选 SFT 补任务接口与高频失败，单测引用、否定和约束变式。用强模型产候选和偏好草稿，先做自动字段与证据位置验收，再抽检语义，保留人工分歧。如果结果可独立验证，再对有限任务做小规模在线反馈；长文及开放任务优先高质量比较和阶段蒸馏。每阶段测原能力回归、教师和验证成本、延迟。若总体分提高但错引或无证据断言增加，暂停扩大训练，回看奖励和数据，并以最小反例重新测量。
