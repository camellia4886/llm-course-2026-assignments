## 如何复核一项结果

以第二讲分段检索为例。中文测试集有 954 题。按前三块计，词汇切分命中 917 题，定长切分命中 923 题；按相同字符预算计，命中数变为 918 和 915。两种口径的差值分别为 −6 和 +3。[原始评估记录](course_labs/results/segmentation_benchmark.json)

从仓库根目录运行以下命令，可用 Python 标准库重建本题的图表数据。

```shell
python "报告/L2-P48 思考题/复算图表数据.py"
```

各题的训练程序、依赖、外部数据及权重准备步骤见[复现指南](docs/复现指南.md)。课堂延伸问题另见[课堂习题](course_labs/课堂习题补全.md)和[思考题合集](思考题合集.md)。
