# 从报告复算到实验重跑

从仓库根目录执行以下命令。若要核对报告中的数字，先按题号打开 Word，选一张图，从同目录的脚本重算。若要检验换一批样例或换一套模型后结论是否成立，再准备相应数据和权重，运行下列实验入口。[按课件题号查报告](../README.md)

## 用已有记录复算一张图

例如，L2-P48 比较词汇切分与定长切分。用标准库 Python 即可重算，无需安装训练依赖。

```bash
python "报告/L2-P48 思考题/复算图表数据.py"
```

先用中文的 954 题核对一次。固定前三块时，词汇切分比定长少命中 6 题；固定 842 字符的阅读预算后，多命中 3 题。两处都用同一批题，改变的是阅读限制。英文使用自己的分母和字符预算。可在原记录的 `languages.zh.retrieval` 下查看三种切分策略，再对照 Word 图中的正负方向。[原始检索记录](../course_labs/results/segmentation_benchmark.json)

其他题将命令中的目录替换成相应题名。L1-P174 与 L2-P13 运行报告随附的自拟短句和确定性规则，得到的是构造样例上的结果。L2-P225 从模型配置推导资源需求。涉及模型推理或训练的其余图表可由已保存的记录重算。

## 准备重跑所需的环境和数据

原运行环境为 Windows、Python 3.12、PyTorch 2.11.0（CUDA 12.8）、Transformers 5.23.0、Gensim 4.4.0。重跑模型时按机器选择相应的 PyTorch 构建，再安装项目依赖。FAISS 实验另用 `faiss-cpu==1.13.2`，原生 FastText 实验另用 `fasttext-wheel==0.9.2`。墙钟时间还取决于硬件、缓存和批量配置。[项目依赖](../requirements.txt)

人民日报相关实验使用课程提供的 1998 年 1–6 月带音原件。下面的两个示例路径需替换为实际文件位置。第一条生成 `data/01.txt` 至 `data/06.txt`；第二条按原始文章编号重建一月文章，供新闻分类和代理分段实验使用。[语料与清理规则](../data/README.md)

```bash
python task1_ngram/clean_corpus.py --source-dir "/path/to/1998-上半年-带音"
python task4_gensim/prep_articles.py --source "/path/to/1998-上半年-带音/1998-01-2003版-带音.txt"
```

独立词向量训练使用 `cmrc2018_train.json`，中英文自然段落检索使用 `DRCD_dev.json`、`squad_dev_v11.json`。按说明放入 `data/public_benchmarks/` 并核对 SHA-256。[原始数据下载位置与散列](../data/public_benchmarks/README.md)

首次重跑会写入对应的 `results/`，训练还会生成新权重。若要对照随仓库提交的记录，可在另一份检出中重跑。

## 选择对应题目的实验

下表中的 Python 文件路径均相对于仓库根目录。以 `python 路径` 执行，带参数的条目保留整行参数。同一行有多个步骤时按列出顺序运行。

| 课件题号 | 实验入口 | 输入与验收 |
|---|---|---|
| L1-P122、P125 | `course_labs/nll_check.py`；`task1_ngram/run_experiments.py`、`task1_ngram/ppl_extra.py`、`task1_ngram/smoke.py` | NLL 用固定张量；n-gram 使用清理后的月度新闻。剪枝对照看 `ppl_trigram_prune.json` 的六月困惑度和完整用时。 |
| L1-P174、L2-P13 | 运行对应报告目录的 `复算图表数据.py` | 两题各有 12 条自拟输入。沿同一行核对期望输出、两条规则的输出和误判。 |
| L1-P167 | `task8_sensitive/run_mini_demo.py` | 脚本内置 8 条样例，核对 `mini_demo.json` 中的接收者、识别依据和最终决定。 |
| L1-P192 | `l1_optional_checkable/guwen_vs_baihua.py` | 先取得下方 L2-P68 新闻标点检查点，或用 `BERT_PUNCT_DIR` 指向同规格检查点。每篇古文和白话各算一次，比较 `per_text`。 |
| L2-P48 | `course_labs/segmentation_benchmark.py` | 读取 DRCD 与 SQuAD，比较同一语言的前三块与字符预算召回。补充代理实验 `course_labs/segment_text.py` 另读一月重建文章。 |
| L2-P137 | `task4_gensim/run_gensim.py --cmrc-train data/public_benchmarks/cmrc2018_train.json` | 报告 v3 用 CMRC 正文训练向量，以一月文章分类。不带参数的 v2 使用 4–6 月新闻。独立的监督 FastText 对照运行 `task4_gensim/official_fasttext.py`。 |
| L2-P68 | `task6_bert/build_data.py` → `task6_bert/train_punct.py` → `task6_bert/reeval.py` → `task6_bert/batch_decode.py` | 一月训练、二月验证、三月留出。可用 `BERT_BASE_MODEL` 指定基础检查点，训练输出到 `task6_bert/results/bert_punct/`；批量解码另计相同切窗策略下的调用和墙钟。 |
| L2-P91 | `course_labs/next_bert_probe.py` | 生成构造任务，训练四组小模型。检查短距与长距答案准确率，并单看检索头的定位成绩；三亿参数方案为设计口径。 |
| L2-P95 | `course_labs/nanogpt_exercise.py` | 使用 `data/05.txt` 和 `data/06.txt`，CPU 运行小型重建，留出损失在训练前后计算。 |
| L2-P225 | `task2_ledger/calc.py` | 根据给定参数推导权重、KV 缓存与计算量。先核对整数字节，再区分 GB 与 GiB。 |
| L3-P15 | `course_labs/safety_boundary_check.py`、`course_labs/safety_boundary_model.py` | 前者核对应用规则；后者使用 Qwen 在本地测试角色、资源和备注的 18 种组合。模型建议为三分类，应用决策为是否放行。 |
| L3-P57 | `course_labs/sft_loss_check.py` | 固定张量用于比较损失均值；对话掩码使用 Qwen 分词器。此脚本从仓库上一级的 `models/qwen2.5-1.5b-instruct/` 读取本地分词器。 |
| L3-P89 | `task16_prompteng/summarize_v2.py`；重新生成用 `task16_prompteng/run_controlled_v2.py` | 仅汇总时直接使用 `results/v2/` 内的候选和评分。重新生成后需按锁定规则重新匿名复核，再运行汇总；旧评分与旧候选绑定。 |
| L3-P226 | `task3_survey/run_tiny_posttrain.py` | 在 CPU 上用相同的 123 个训练组合比较 SFT 和组相对更新，留出 21 个组合；逐次对照正确数、参数更新数和奖励调用数。 |
| L3-P233 | `task17_domain/run_domain_sft.py` → `task17_domain/error_examples.py` | 先完成 L2-P68，保留新闻检查点和月度断句数据。微调使用 `task17_domain/guwen.tsv`，短句干预使用 `constraint_variants.tsv`；按完整古文、构造短句和现代新闻分别核对。 |

原生 KenLM 需要可执行的 `lmplz` 与 `query`。从仓库根目录运行 `python task1_ngram/kenlm_experiment.py --lmplz "/path/to/lmplz" --query "/path/to/query"`。未指定 `--query` 时脚本在 `lmplz` 所在目录查找。三个训练规模与对应词数、ARPA 字节数均写入同一份记录。[KenLM 结果](../task1_ngram/results/kenlm.json)

分词和索引的补充练习分别运行 `python course_labs/data_and_tokenizers.py`、`python course_labs/faiss_search.py`，均需预备清理后的 `data/04.txt`。前者按模型名读取本地已缓存的 `bert-base-chinese` 分词器；后者加载 BERT 与 FAISS，支持 `BERT_BASE_MODEL`。L3-P15 的模型实验与 L3-P89 的译诗生成均支持通过 `QWEN_MODEL_DIR` 指定 Qwen2.5-1.5B-Instruct 的本地目录。
