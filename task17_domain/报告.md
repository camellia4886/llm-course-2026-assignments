# 有限预算下的古文标点领域适配

对应 L3 Part 2 第 233 页。研究目标是检验少量选编示范和句末语气词规则能否改善新闻 BERT 在古文上的标点，同时保留现代新闻能力。

## 抽样与干预

基线为任务 7 重新微调的 8 类检查点。五篇 SFT 范例为《岳阳楼记》《醉翁亭记》《爱莲说》《陋室铭》《马说》，共 1,121 字；独立古文为《桃花源记》《师说》，共 776 字。现代回归取任务 7 精确去重后的三月独立样本前 2,000 条。古文标点采用所附教学版本，不同版本可能在逗号、句号和分号上有合理差异。测试篇章没有进入领域 SFT。

精选 SFT 为全参数 AdamW、8 轮、batch=4、学习率 2×10⁻⁵、seed=42。规则通过标点符号查 ID，模型为空位时，给“乎、邪、耶、哉、欤”补问号，给“也、矣、焉、耳”补句号。规则不显式建模上下文。预期改进是句末问句检出增加，反例是句中介词、发语成分和原有现代文能力受损。

## 四臂对照

| 条件 | 古文宏 F1 | 古文七类标点宏 F1 | 现代文宏 F1 |
|---|---:|---:|---:|
| 基线 | 0.4062 | 0.3306 | 0.5529 |
| 基线 + 规则 | 0.3605 | 0.2788 | 0.5368 |
| 精选 SFT | **0.4197** | **0.3454** | 0.5460 |
| 精选 SFT + 规则 | 0.3691 | 0.2884 | 0.5297 |

单独 SFT 的古文宏 F1 升 1.35 个百分点，其中问号从 0.50 升到 0.80。同期古文句号 F1 从 0.5783 降到 0.5195，现代回归下降约 0.69 个百分点，因此保留类级权衡。规则在两种模型上均下拉古文和现代文指标。

旧报告中的规则错误把疑问语气词写成标签 7（叹号）。固定旧权重和旧样本、仅改标签再次核验时，旧「SFT＋规则」的古文宏 F1 从 0.5085 降到 0.4229，低于旧 SFT 的 0.4703。上表是新基线下的完整重跑，不使用旧错误作为证据。

## 变式、错误和成本

新增 6 对、12 条自拟教学变式，覆盖句末疑问与句中“乎”、陈述与反问、叹句和问句、句中与句末“也”、陈述尾词和句中“焉”。短句完全匹配数为基线 2/12、基线加规则 8/12、SFT 6/12、SFT 加规则 8/12。基线没有给「此事合礼乎」断句，规则正确补问号。相邻对照「此事合乎礼」却被改为「此事合乎？礼」。短样本的局部收益与长篇宏 F1 下降同时出现。《师说》中 SFT 仍会漏掉「孰能无惑」末问号，同时部分句号变成逗号。全文逐位置差异可回查。

本机 RTX 5060 Laptop 实测基线评测 6.2 秒，SFT 训练 1.3 秒，SFT 后评测 5.7 秒。另需录入校对、选择训练篇目和制作变式的人力，旧过程估计约 30–40 分钟古文整理、约 20 分钟规则草拟与测试，本轮未完整用计时器记录人工时间。运行无 API 费用。由于仅两篇古文、单 seed，结论限定于本次测试。一个可推翻当前判断的后续对照是对照同批语气词只在由上下文确认句末时启用规则，并在独立篇目报告问号收益与误断率。
